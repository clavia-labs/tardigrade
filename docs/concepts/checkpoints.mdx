## Save state and position

```text
regular atom ──┐
family member ┼──→ snapshot(state, cursor) ──→ SQLite
family member ┘
```

## Configure checkpointing

```ts
import { Effect, Layer } from "effect"
import { host } from "tardie/platform/bun"
import { meeseeks } from "./actor"

const runtime = await Effect.runPromise(host(meeseeks, {
  storage: ".tardigrade",
  layer: Layer.empty,
  checkpointPolicy: {
    mode: "threshold",
    options: { everyEvents: 100 },
  },
}))
```

## Recover state

```text
saved atom state + events after its cursor → current atom state
```
