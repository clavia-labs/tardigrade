In Tardigrade, a library adapts an Effect `Service` with agent metadata. You can think of them as pluggable capabilities for your agents, declared using the type system. The following example walks you through what this means using the `Workspace` library.

<Tip title="Prototype API">

`Library.from` and `host` are part of the [service-library prototype](https://github.com/clavia-labs/tardigrade/pull/855). The provider examples below show the proposed unified `Workspace` contract. The built-in providers expose `FilesystemWorkspace` in the prototype; supplying the custom service directly requires their interface migration.

</Tip>

## Workspace

This example shows how you can give your cloud agents the capability to use the filesystem and run `bash` commands. We'll define this as a `Workspace` library built on top of a `Context.Service` and implemented using `Layer`.

## Declare the Interface

Effect services define the interface of a capability. For this example, the workspace service exposes `bash` and `read`.

```ts title="workspace.ts"
import { Context, Effect } from "effect"
import type { ToolResult } from "tardie/libraries"

export class Workspace extends Context.Service<Workspace, {
  readonly bash: (input: { command: string }) => Effect.Effect<string, string>
  readonly read: (input: { path: string }) => Effect.Effect<typeof ToolResult.Type, string>
}>()("Workspace") {}
```

## Add agent metadata

In `workspace-library.ts`, create your library from the `Workspace` service by adding agent metadata. This includes adding input and output schemas. You can also optionally annotate methods with descriptions and hints.

```ts title="workspace-library.ts"
import { Schema } from "effect"
import { Rpc } from "effect/rpc"
import { Library, MethodDescription, MethodHints, ToolResult } from "tardie/libraries"
import { Workspace } from "./workspace"

export const workspace = Library.from(Workspace, {
  name: "workspace",
  description: "Files and a shell in the agent's workspace",
  toolNames: { bash: "bash", read: "read" },
  methods: [
    Rpc.make("bash", {
      payload: Schema.Struct({ command: Schema.String }),
      success: Schema.String,
      error: Schema.String,
    }).annotate(MethodDescription, "Run a shell command in the workspace"),
    Rpc.make("read", {
      payload: Schema.Struct({ path: Schema.String }),
      success: ToolResult,
      error: Schema.String,
    })
      .annotate(MethodDescription, "Read a file from the workspace")
      .annotate(MethodHints, { readOnlyHint: true, openWorldHint: false }),
  ],
})
```

## Select the library

The agent selects the `workspace` library. Its methods require the ordinary `Workspace` service, and the host derives the tool adapters from this declaration.

```ts title="agent.ts"
import { agent } from "tardie/agent"
import { workspace } from "./workspace-library"

export const assistant = agent({
  name: "researcher",
  system: "Use the workspace to read files and run shell commands.",
  tools: [workspace],
})
```

## Implement using layers

Services define the contracts, libraries add agent metadata, and layers describe how to construct implementations. The same capability can be provided in different ways.

For example, the `Workspace` library can be implemented using a real filesystem and bash through a container. You can also implement the same capability using a virtual filesystem backed by SQLite and virtual bash using a package like `just-bash` within an isolate.

### Container workspace

`client` is a configured Boxd client, and `ModelLive` supplies the model services. `HostThread` is provided by the host when it constructs the layer.

```ts title="worker.ts"
import { Effect, Layer } from "effect"
import { boxdWorkspace, boxdWorkspaceName } from "tardie/platform/boxd"
import { host, HostThread } from "tardie/platform/cloudflare"
import { assistant } from "./agent"
import { client } from "./boxd-client"
import { ModelLive } from "./model-services"

const WorkspaceLive = Layer.unwrap(Effect.map(HostThread, thread =>
  boxdWorkspace({
    client,
    name: boxdWorkspaceName(thread),
    directory: "/home/boxd/workspace",
    network: { mode: "none" },
    release: "retain",
  }),
))

const worker = host(assistant, {
  layer: Layer.mergeAll(ModelLive, WorkspaceLive),
})

export const ActorDO = worker.ActorObject
export const ThreadDO = worker.ThreadObject
export default worker
```

### Virtual workspace

`DurableStorage` supplies the storage of the Durable Object constructing the layer.

```ts title="worker.ts"
import { Effect, Layer } from "effect"
import { host, DurableStorage, virtualWorkspace } from "tardie/platform/cloudflare"
import { assistant } from "./agent"
import { ModelLive } from "./model-services"

const WorkspaceLive = Layer.unwrap(Effect.map(DurableStorage, storage =>
  virtualWorkspace(storage, {
    name: "agent-workspace",
    policy: { maxFileBytes: 8 * 1024 * 1024 },
  }),
))

const worker = host(assistant, {
  layer: Layer.mergeAll(ModelLive, WorkspaceLive),
})

export const ActorDO = worker.ActorObject
export const ThreadDO = worker.ThreadObject
export default worker
```
