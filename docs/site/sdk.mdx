## Install

```bash variant="single"
bun add tardie
```

Most applications can import their actor definition, agent components, policies, and public types from `tardie`:

```ts
import {
  actor,
  agentMethods,
  budget,
  codeMode,
  compaction,
  infer,
  nativeOutput,
  system,
  tool
} from "tardie"
```
