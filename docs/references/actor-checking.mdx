## checkActor

```ts
const report = await checkActor(actor, {
  inputs,                 // arbitrary of { method, input }
  services: testServices,  // context => Effect Layer
  invariants: rules,
  numRuns: 100,
  maxSteps: 100,
  timeoutMs: 5_000,
  seed: 42,               // optional
})
```

Each case starts fresh. `services` supplies required dependencies; fake, real, or mixed. `context.generate(builder, ...args)` records generated service values for shrinking and replay. Use stable builders and deterministic call order.

| Option | Default | Meaning |
| --- | --- | --- |
| `numRuns` | 100 | Generated cases |
| `maxSteps` | 100 | Committed event batches, including initial input |
| `timeoutMs` | 5,000 | Per-case timeout, including Effect service acquisition |

`DEFAULT_ACTOR_CHECK` exports these defaults. The report contains `status`, `seed`, `numRuns`, `boundedRuns`, and `policy`. Status is `"passed"` when executions reach rest, or `"bounded"` when a run needs another batch beyond the limit. Rest does not imply completion. Effects may execute before their batch is refused; timeouts interrupt cooperative Effects only.

## Rules

```ts
import type { Event } from "tardie/core"

type Rule = (context: {
  readonly events: ReadonlyArray<Event>
}) => void | boolean
```

`invariants` maps names to synchronous rules. Each receives a copy of the empty log, then every event prefix. Return `false` or throw to fail; `true` or `void` passes.

## Failures and replay

`ActorCheckError` carries `counterexample`, `seed`, and `numShrinks`. The counterexample contains `events`, `failure`, and the recorded `example`. A rule failure ends at the first violating event.

```ts
const replay = await replayActor(actor, error.counterexample.example, {
  services: testServices,
  invariants: rules,
})
```

Replay returns `status` (`"resting"`, `"bounded"`, or `"failed"`), `steps`, `events`, `example`, and optional `failure`. Generated choices are replayed; ordinary service calls run again. Reproduction requires deterministic services.

The checker covers one invocation; cross-thread delivery and child allocation fail explicitly. Passing provides evidence for sampled executions, without proving every possible execution safe.
