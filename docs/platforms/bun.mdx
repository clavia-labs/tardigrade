The Bun platform runs a Tardigrade actor as a process backed by SQLite. Each actor instance has a directory database, and each thread has its own event log, workspace, runtime, and alarm state.

## Run locally

`tdg init` creates a `server.ts` entry that mounts `actor.ts` and serves its API. Start it through the generated package script:

```bash variant="single"
bun run dev
```

The script loads `.dev.vars`, watches the TypeScript sources, and restarts the server after an edit. The server listens on port `4242` by default. Its health endpoint is available at `/healthz`.

Run the Cloudflare Worker locally when you need the Durable Object runtime:

```bash variant="single"
bun run dev:cloudflare
```

## Provide application services

An actor that requires an application Effect service can define a Layer factory and pass it to `layerActorThreads` in `server.ts`:

```ts title="server.ts"
import { Layer } from "effect"
import { layerActorThreads, type ActorThreadLayersFor } from "tardie/server/host"
import { AppConfig } from "./application"
import definition from "./actor"

const layersFor = (({ thread }) =>
  Layer.succeed(AppConfig, { thread })) satisfies ActorThreadLayersFor<typeof definition>

const threads = Layer.provide(
  layerActorThreads(definition, { inferenceObserver: inference.observer, layersFor }),
  [configLayer, catalog]
)
```

The factory receives `actorInstance` and the internal thread address, such as `ag.root`. A Layer factory is optional when the actor has no application service requirements.

## Storage

The default actor database is `.tardigrade/actor.sqlite`. Thread databases live beside it under `.tardigrade/actor.sqlite.threads/`. The host persists events before running the work they enable, so it can resume unfinished work after the process restarts.

## Configure

`tdg setup` writes model configuration to `wrangler.jsonc` and local credentials to `.dev.vars`. The generated development script loads `.dev.vars`. A hosted process can provide the same credential names through its environment.

Set `PORT` to change the HTTP port and `TARDIGRADE_DB` to change the SQLite database path.
